Privacy Policy

Last updated: August 2026

This policy covers personal software tools built and operated solely by Justin Smith for his own use — including tools that connect to Google APIs (such as Google Calendar) on his own Google account.

What this is

These are single-user personal automation tools, not a public product or service. No one other than Justin Smith uses them or has access to the data they touch.

Data accessed

Where a tool connects to a Google API, it accesses only the data needed for that tool's function (for example, calendar events) on Justin Smith's own Google account, using an OAuth token he grants and controls directly.

Data sharing

No data is sold, shared, published, or made available to any third party. Data is not used for advertising, profiling, or any purpose beyond operating the tool for its owner.

Data storage

Access tokens and any cached data are stored locally on Justin Smith's own devices and infrastructure. Nothing is transmitted to or stored on third-party servers beyond the Google APIs the tool directly calls.

Revoking access

Access can be revoked at any time from Google Account → Security → Third-party access.

Questions about this policy: see contact details at justintsmith.github.io.
