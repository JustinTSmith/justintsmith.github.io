gbrain

A private, single-user personal knowledge assistant, operated by Justin Smith.

gbrain keeps a searchable personal knowledge base on its operator's own computer. It is a private tool built and run by one person for their own use. It is not a product, not a service, and is not offered to or used by anyone else. There is no sign-up and no other users.

What gbrain connects to

With the operator's explicit consent, gbrain reads the operator's own Google data using read-only access:

  • Gmail (gmail.readonly) — message threads, so the operator can find their own past correspondence and track outstanding replies.
  • Google Calendar (calendar.readonly) — events, to keep a searchable history of the operator's own meetings.
  • Google Contacts (contacts.readonly) — names and addresses, to resolve who appears in that history.

gbrain never sends email, never modifies calendars, and never changes contacts. All retrieved data stays on the operator's own machine.

Where data goes

Nowhere. Retrieved content and OAuth tokens are stored locally on the operator's own computer. Nothing is uploaded to any server controlled by this application, and no data is sold, shared, or used for advertising, profiling, or model training.

Revoking access

Access can be withdrawn at any time from Google Account → Third-party access, which immediately ends gbrain's ability to read any further data.
